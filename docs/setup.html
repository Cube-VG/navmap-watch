Before you start

You need a supported Garmin AMOLED watch, an Android phone running Android 8.0 or newer, and Google Maps and Garmin Connect installed. Pair the watch in Garmin Connect first.

Map images and route lines also need your own Google Cloud project with billing enabled. Google provides monthly free usage caps; charges apply beyond those caps. Review the current Google Maps pricing.

NavMap is available on the Connect IQ Store. Developers can instead build the watch app from source. NavBridge is free.

Get the two apps

NavBridge on Android

Download the signed APK from the project’s GitHub release, then open it on your phone. Android may ask you to allow installation from your browser or Files app.

Download NavBridge

Release notes and checksums are available alongside the download.

NavMap on your Garmin

Install NavMap from the Connect IQ Store. Precompiled watch packages are not distributed through this site; source-build instructions are linked below.

Google Maps key optional

Good news: turn arrows, street names, distance countdowns and vibration alerts work free out of the box with no key at all. A Google Maps key is only needed if you want full visual satellite or street map backgrounds on your watch.

Google provides a monthly free credit for every Google account, which covers thousands of map views, so personal use usually costs nothing.

  1. Open Google Cloud Console Credentials and sign in with your Google account.
  2. Tap + CREATE CREDENTIALS → API key.
  3. Copy your new API key.
  4. Switch to NavBridge on your phone — it detects the copied key from your clipboard and offers to save it in one tap.

Review your usage in Google Cloud. Google’s cost controls guide explains quotas and budget alerts.

Give the phone its permissions

Work through the Setup list inside NavBridge.

  • Notification access: lets NavBridge read Google Maps’ navigation notification. For a sideloaded APK, Android may first require App info → ⋮ → Allow restricted settings.
  • Notifications: lets NavBridge remind you when the watch needs a button press.
  • Battery settings: set both NavBridge and Garmin Connect to Unrestricted so Android can keep the connection alive in the background.
  • Location (optional): lets NavBridge use the phone’s position as the start of a shared route. The watch uses its own GPS for the map display.

Under I travel by, choose your travel mode. NavBridge defaults to Auto, which follows whatever mode Google Maps is using — car, motorbike, bicycle or walking — without routing errors.

Pair, then try a demo

  1. Keep NavBridge open on the phone and open NavMap from the watch’s app list.
  2. Wait for NavBridge’s Watch card to say Paired with NavMap. It will send the Maps key to your watch.
  3. Tap Simulate navigation in NavBridge. You should see a turn arrow, a distance and an arrival time on the watch.
  4. Go outside so the watch can acquire GPS. The map and route line need the watch’s position before they can appear.

If the watch asks to open NavMap, confirm on the watch. For longer trips, open NavMap directly from the watch’s app list before you start navigation.

Pick a destination

Turns and a blue route line

Find a destination in Google Maps, tap Share, then choose Navigate with NavMap. NavBridge requests the route and starts Google Maps navigation. If you go off route, it requests an updated line.

Turn guidance only

Start navigation with Google Maps’ regular Start button. NavMap receives the turn directions, distance and arrival time, but Google Maps does not share the route line through its notifications.

While you travel

NavMap gives a long buzz about 25 seconds before a turn and three short buzzes about 6 seconds before, based on your speed. Between turns the display may dim to the next arrow and distance. Raise your wrist or press a button to see the map.

New map images and rerouting need internet. Existing turn guidance can continue while Google Maps still provides notifications, and an already-received route can stay visible. Your phone must stay connected to the watch.

Build from source

The source is public. Developers can use the Connect IQ SDK to build NavMap for a supported device. The build guide covers signing, device selection and installing your own build.

git clone https://github.com/Cube-VG/navmap-watch.git

Follow the developer build guide →

The older setup scripts expect watch files in GitHub releases. Those files are no longer part of the current release, so use the source-build instructions instead of the old automatic download flow.

If something is not working

Check that NavBridge’s Setup items are complete, Garmin Connect is connected, and the Watch card says Paired with NavMap. A missing map usually means the watch is waiting for GPS, or the key’s Maps Static API or billing setup needs attention.

For specific messages, read the full troubleshooting guide. You can also open a GitHub issue. Review any logs before sharing them; they can include your destination.

Admin Mode: tap the NavBridge title 7 times inside the phone app to unlock the developer log console and live notification inspector.
