# Google Maps notification fixtures

`google-maps.json` comes from [PebbleNTN](https://github.com/optio/PebbleNTN)
(`rules/fixtures/google-maps.json`) and is used here unchanged under the MIT License in `LICENSE`.
It holds 174 Google Maps navigation notifications, real captures and hand-written ones, in 17 locales.
NavBridge's parser tests read it to check distances, ETAs and maneuver text.
