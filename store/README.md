# Store listing assets

Artwork for the **Garmin Connect IQ Store** listing of NavMap (see `PLAN.md`, step 5).

These files were previously loose in the repository root and untracked. They are not
referenced by the website in `docs/` — that site uses the WebP derivatives in
`docs/assets/`.

| File | Size | Intended slot |
|---|---|---|
| `cover_image_500x500.png` | 500×500 PNG | Store app icon |
| `hero_image_1440x720.png` | 1440×720 PNG | Optional hero / promotional image |
| `navmap-icon-500x500.gif` | 500×500 GIF | Animated app icon (marketing use) |
| `navmap_studio_showcase.jpg` | 1000×1000 JPEG | Showcase / screenshot |
| `watch-map.gif` | 390×390 GIF | Watch map screen animation |

## Before submitting

Confirm each slot against Garmin's current requirements at
<https://developer.garmin.com/connect-iq/core-topics/publishing-to-the-store/> —
screenshot limits and accepted formats change. Note in particular that the store's
app icon is documented as a **PNG**; the 500×500 GIF here is for marketing use, not
the listing icon.

Source artwork for the site derivatives lives in `docs/assets/`. Do not duplicate
those files here.
