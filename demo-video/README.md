# NavMap demo video

A 28-second product demo of NavMap (Google Maps route → Garmin watch), built with [Remotion](https://remotion.dev) in React + TypeScript. Every screen, device and icon is drawn in code; there are no real Google, Apple or Garmin logos and no image assets.

| Composition | Size | Output |
|---|---|---|
| `NavMapDemo` | 1920 × 1080, 30 fps | `out/navmap-demo.mp4` |
| `NavMapDemoVertical` | 1080 × 1920, 30 fps (Reels / Shorts, phone above watch) | `out/navmap-demo-vertical.mp4` |

## Commands

```bash
npm install
npm run dev              # Remotion Studio, scrub the timeline
npm run render           # both MP4s into out/
npm run stills           # one frame from the middle of each scene of both MP4s, into out/stills/
npm run frames -- NavMapDemo /tmp/frames 120 300   # render single frames from source, no MP4 needed
npm run sounds           # regenerate the UI sounds in public/audio/ with ffmpeg
npm run typecheck
```

On a machine without internet access, point Remotion at a local Chrome Headless Shell: `REMOTION_BROWSER_EXECUTABLE=/path/to/headless_shell npm run render`.

## Retiming

All timings live in [`src/timings.ts`](src/timings.ts), in frames at 30 fps:

- `SCENES`: the 8 storyboard scenes
- `TAPS`: when the UI reacts to each tap; the tap circle lands `TAP_LEAD` (6) frames earlier
- `T`: every other event (sheet in, progress ring, pulse, buzz, countdown, map open, end card)
- `CAPTIONS`, `CAMERA`, `GLOW`, `SOUNDS`, `DRIVE`

## Layout

```
src/
  timings.ts            all scene and event timings
  layouts.ts            device positions for the landscape and vertical versions
  NavMapDemo.tsx        stage: background, camera, devices, captions, title/end cards, sounds
  components/
    IPhoneFrame.tsx     iPhone 16 Pro frame: Dynamic Island, status bar (9:41, 5G, full battery)
    GarminFrame.tsx     round 5-button watch, strap edges, 454 × 454 screen, vibration arcs
    TapIndicator.tsx    fingertip circle with ripple
    MapCanvas.tsx       SVG map renderer shared by the phone and the watch
    BluetoothPulse.tsx  dotted arc with pulses from phone to watch
    …                   title card, end card, captions, background, icons, NavMap icon
  screens/
    phone/  MapsRoutePreview, MapsNavigating, ShareSheet, NavMapSending
    watch/  WatchFace, WatchNotification, WatchMap
  lib/
    mapData.ts          the made-up street grid and the route both devices draw
    anim.ts, drive.ts   easing/spring helpers, car position and distance to the turn
```

Fonts: Inter, bundled from `@fontsource/inter` (SIL Open Font License). Sounds: sine blips and filtered noise generated by `scripts/make-sounds.sh`; no samples, no music.
